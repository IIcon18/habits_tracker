# 10 · Чек-лист готового экрана

Проверяй каждый экран перед тем, как считать его готовым.

## Визуально

- [ ] Сравнил со скриншотом из `screens/` бок о бок на ширине 390px: отступы, размеры шрифтов, радиусы совпадают.
- [ ] Все цвета — переменные из `tokens.css`, в коде нет «сырых» hex.
- [ ] Экран выглядит правильно в тёмной **и** светлой теме (`data-theme="light"`).
- [ ] На ширине 320px ничего не обрезается и не налезает; на 480px не растягивается некрасиво.
- [ ] Нет видимых полос прокрутки.
- [ ] Нет теней у карточек, градиентов, эмодзи, капслока.

## Telegram

- [ ] Нет своей шапки и своей кнопки «Назад»; BackButton/MainButton/SecondaryButton настроены по таблице из `05-screens.md`.
- [ ] Цвет шапки и нижней панели Telegram = `--ground`, меняется вместе с темой.
- [ ] Контент не прячется под MainButton и за безопасными зонами.

## Поведение

- [ ] Отметка — одно касание, кнопки ≥56px; работает haptic.
- [ ] Анимация капли совпадает с `reference/today-prototype.html`; при reduced motion её нет.
- [ ] Логика серии и пропусков соответствует `01-product.md` (один пропуск не сбрасывает, два — сбрасывают).
- [ ] Отмена отметки возвращает карточку, голоса, серию и воду в шапке.
- [ ] Без сети отметки сохраняются и отправляются позже; при ошибке — тост с «Повторить».

## Тексты и доступность

- [ ] Тексты дословно из `08-copy.md`, числа склоняются.
- [ ] Все нажимаемые элементы — `<button>` или `<a>`, у иконок без подписи есть `aria-label`.
- [ ] Контраст текста ≥ 4.5:1 (значения токенов уже проверены — не меняй пары).
