# Капля — дизайн для вёрстки

Папка с макетами и правилами для Claude Code.

## Как подключить

1. Положи папку `design/` в корень проекта.
2. Добавь в корневой `CLAUDE.md` проекта (создай файл, если его нет) строку:

   ```
   Интерфейс верстаем строго по папке design/. Перед любой работой с UI прочитай design/CLAUDE.md и следуй ему.
   ```

3. Дальше можно просить Claude Code по шагам, например:
   - «Сверстай токены и экран Сегодня (1.1) по папке design»
   - «Добавь карточку привычки со всеми состояниями из 3.1»
   - «Сделай мастер создания привычки 5.1–5.4»

## Что внутри

| Путь | Что это |
| --- | --- |
| `CLAUDE.md` | главная инструкция для Claude Code |
| `01-product.md` … `10-checklist.md` | продукт и логика, токены, сетка, компоненты, экраны, анимация, Telegram, тексты, бот, чек-лист |
| `tokens/tokens.css` | все цвета, шрифты, отступы и радиусы в CSS-переменных — подключать в проект как есть |
| `tokens/tokens.json` | те же значения в данных |
| `screens/` | 30 экранов в PNG (2x), имя файла = номер экрана из `05-screens.md` |
| `sheets/` | обзорные листы по разделам |
| `reference/` | живые HTML-прототипы: экран «Сегодня» с анимацией капли и состояния карточки |

## Порядок вёрстки (рекомендуемый)

1. Токены, шрифты, тема и интеграция с Telegram (`02`, `03`, `07`).
2. Карточка привычки и ряд дней (`04`, экран 3.1).
3. Экран «Сегодня» с анимацией капли (1.1–1.4, `06`).
4. Мастер создания (5.1–5.4) с подсказкой ИИ.
5. Напоминание, редактирование, удаление (6.x).
6. Знакомство и пустое состояние (2.x).
7. Итог месяца и шеринг (7.x).
8. Лимит, офлайн, ошибки (9.x).
9. Сообщения бота (`09`).
