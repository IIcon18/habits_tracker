# 03 · Сетка, безопасные зоны, касания

## Экран

- Макеты нарисованы под ширину 390px; вёрстка резиновая от 320 до 480px, только мобильная.
- Боковые поля экрана `--space-4` (16px); у заголовков экрана и шапки дня — `--space-5` (20px).
- Между карточками `--space-3` (12px).
- Внутренний отступ карточки: 18px сверху и по бокам, 16px снизу.
- Полосы прокрутки скрыты (`scrollbar-width: none` и `::-webkit-scrollbar { display: none }`), прокрутка работает.

## Безопасные зоны Telegram

- Сверху — шапка Telegram («Закрыть / Капля / ···»). На макетах она нарисована высотой 56px только для наглядности; в коде её нет.
- Отступы бери из `Telegram.WebApp.safeAreaInset` и `contentSafeAreaInset` (или CSS-переменных `--tg-safe-area-inset-*`, `--tg-content-safe-area-inset-*`) и следи за событиями `safeAreaChanged` / `contentSafeAreaChanged`.
- Когда показана MainButton, последний элемент контента должен оставаться виден над ней: добавь снизу `--space-6` + высоту нижней панели.
- Используй `Telegram.WebApp.viewportStableHeight` для высоты экрана, а не `100vh`.

## Касания

- Кнопки отметки «Сделал» / «Хотя бы 2 минуты» — высота `--tap-min` (56px), по половине ширины карточки, всегда внизу карточки (зона большого пальца).
- Любой нажимаемый элемент — не меньше 44×44px (чипы 40px высотой допустимы с увеличенной зоной касания).
- На каждую отметку — `HapticFeedback.impactOccurred('light')`, на успешное сохранение — `notificationOccurred('success')`.
