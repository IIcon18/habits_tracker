# 02 · Токены

Источник истины — `tokens/tokens.css` (CSS-переменные) и `tokens/tokens.json` (те же значения в данных). Подключай `tokens.css` один раз в корне приложения.

## Цвет — как применять

| Токен | Где |
| --- | --- |
| `--ground` | фон экрана; передаётся в `setHeaderColor`, `setBackgroundColor`, `setBottomBarColor` |
| `--surface` | карточки, поля ввода, группы списков, нижние листы |
| `--surface-sunk` | блок подсказки ИИ, кнопка «···», неактивная MainButton |
| `--surface-raised` | тост «Отметка не сохранилась» |
| `--ink` / `--ink-muted` | основной и вторичный текст |
| `--line` | разделители 1px |
| `--accent` + `--on-accent` | только полное выполнение и главное действие: «Сделал», MainButton, заполненная ячейка дня, капля |
| `--accent-soft` + `--on-accent-soft` | «2 минуты», вторичные кнопки, вода в шапке дня, выбранный чип |
| `--accent-ink` | ссылки и акцентный текст: «Отменить», «Взять», «Ещё варианты» |
| `--amber*` | только предупреждения: два пропуска подряд, бот не может писать |

Красного в приложении нет. Удаление подтверждает системное окно Telegram (`showPopup` с кнопкой `destructive`).

## Типографика

- **Unbounded** (`--font-display`) — дата, идентичность, заголовки экранов и разделов, крупные числа. Не больше одного-двух мест на экране.
- **Manrope** (`--font-text`) — всё остальное.
- Шкала — классы `.t-*` в `tokens.css`. Крупные числа на отдельных экранах: «23» в итоге месяца — Unbounded 72/72, время напоминания «07:45» — Unbounded 56/56, заголовки знакомства — Unbounded 28/34.
