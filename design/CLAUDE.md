# Капля — инструкция по вёрстке для Claude Code

Ты верстаешь Telegram Mini App «Капля» — трекер маленьких привычек. Всё, что нужно для вёрстки, лежит в этой папке. Макеты утверждены: повторяй их, а не придумывай заново.

## Как работать

1. Прочитай файлы по порядку, прежде чем писать код:
   - `01-product.md` — что это за продукт и правила логики (серия, пропуски, голоса);
   - `02-tokens.md` и `tokens/` — цвета, шрифты, отступы, радиусы;
   - `03-layout.md` — сетка, безопасные зоны Telegram, размеры касаний;
   - `04-components.md` — компоненты и их состояния;
   - `05-screens.md` — каждый экран: назначение, содержимое, кнопки Telegram, картинка-эталон;
   - `06-motion.md` — анимация капли и другие переходы;
   - `07-telegram.md` — интеграция с Telegram Web App API;
   - `08-copy.md` — все тексты интерфейса;
   - `09-bot.md` — сообщения бота и кнопки;
   - `10-checklist.md` — по нему проверяй каждый готовый экран.
2. Картинки-эталоны лежат в `screens/` (по одному экрану, в 2x) и `sheets/` (обзор разделов). Перед вёрсткой экрана открой его PNG и сверяйся с ним.
3. В `reference/` есть два живых HTML-прототипа: экран «Сегодня» с анимацией капли и все состояния карточки. Из них можно брать точные CSS-значения и ключевые кадры анимации.

## Стек

- Если в проекте уже есть стек — используй его, не меняй без запроса.
- Если проект пустой, по умолчанию: Vite + React + TypeScript, CSS-переменные из `tokens/tokens.css` (без Tailwind и UI-китов), официальный скрипт `https://telegram.org/js/telegram-web-app.js` или пакет `@telegram-apps/sdk`.

## Жёсткие правила

- Цвета, размеры шрифтов, отступы и радиусы — только через переменные из `tokens/tokens.css`. Никаких «примерно похожих» значений в коде.
- Основная тема — тёмная. Светлая включается сама по `Telegram.WebApp.colorScheme`; своего переключателя темы нет.
- Шапку, кнопку «Назад» и главную кнопку внизу не рисуй сам: это `BackButton`, `MainButton`, `SecondaryButton` Telegram (см. `07-telegram.md`). На макетах они нарисованы только для наглядности.
- Кнопки отметки — не ниже 56px, все нажимаемые элементы — не меньше 44×44px.
- Тексты бери дословно из `08-copy.md`: на «ты», без восклицательных знаков, без капслока.
- Числа склоняй по-русски (1 голос, 2 голоса, 5 голосов; 1 день, 2 дня, 5 дней).
- Никаких декоративных градиентов, теней у карточек, эмодзи и иконок капель по всему интерфейсу. Метафора воды держится на одной детали — воде в шапке дня и падающей капле.
- Контраст текста не ниже 4.5:1 в обеих темах (значения в токенах уже проверены).
- Уважай `prefers-reduced-motion`: без падения капли, ячейка заполняется сразу.

## Открытые решения

- Создание привычки: в макетах два варианта — пошаговый мастер (раздел 5) и один экран (раздел 4). По умолчанию верстай мастер; один экран — только если попросят.
- Палитра: базовая «Ночная вода» (в `tokens.css`). Альтернативы из `screens/10.1-palettes.png` описаны в `02-tokens.md`; не внедряй их без запроса.
- В карточке для шеринга вместо имени бота стоит `[@ИМЯ_БОТА]` — возьми из конфига или спроси.
