# 05 · Экраны

Каждый экран — PNG в `screens/`. Маршруты — предложение, можно менять. «MainButton», «SecondaryButton», «BackButton» — системные кнопки Telegram.

## Навигация

```
первый запуск → /intro/1 → /intro/2 → /intro/3 → /new (мастер) → /today
/today ─ идентичность на карточке → /habit/:id → /habit/:id/month → /habit/:id/share
                                       ├→ /habit/:id/reminder
                                       └→ удаление (showPopup) → /today или /empty
/today ─ «Добавить привычку» при 3 активных → лист лимита (9.1)
```
